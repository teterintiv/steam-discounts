# Скидки Steam

Учебный проект Тетерина Тимофея Ивановича.

Сайт: https://steam-discounts.netlify.app/

Выбор 12 стран, цены в валюте магазина Steam и примерный пересчёт в рубли. Есть поиск, фильтр от 50%, сортировка, избранное и страницы по 25 игр. Цены запрашиваются сервером, компьютер автора для работы сайта не нужен.

В этом репозитории лежит готовая сборка для Netlify. prepare.mjs подготавливает public/ и серверную функцию. server.mjs содержит собранный сервер. В архиве project-source.zip находятся исходники, локальный запуск и проверки.

Steam Store и ЦБ РФ используются как источники цен и курса валют. Избранное хранится в браузере. Некоторые игры и способы оплаты доступны не во всех странах. Покупка происходит на сайте Steam.
