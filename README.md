# Скидки Steam

Автор: Тетерин Тимофей Иванович.

Сайт показывает скидки Steam для 12 стран. Регион выбирается в верхней части страницы. Цены указаны в валюте магазина, рядом есть приблизительный пересчёт в рубли по курсу ЦБ РФ.

Есть поиск, сортировка, фильтр от 50%, избранное и страницы по 25 игр. Выбранная страна и избранное сохраняются в браузере. Регистрация не нужна. Если Steam временно не отвечает, остаётся сохранённая подборка с датой получения.

Данные берутся из Steam Store: /search/results/ и /api/featuredcategories/. Курс валют: https://www.cbr.ru/scripts/XML_daily.asp. Даты окончания акций выводятся только там, где Steam их передал. Это подборка популярных предложений, а не полный каталог магазина.

Онлайн: https://steam-kz-sales-teterin.optimisticrobin64.chatgpt.site/

Локально: Node.js 22 или новее, затем start.cmd и http://127.0.0.1:8092. Дополнительные библиотеки не нужны. После изменения файлов можно собрать проект командой npm run build.

public/ содержит страницы, стили, клиентский JavaScript и сохранённые данные. worker.js получает цены на сервере. build.mjs собирает сервер и страницы в dist/server/index.js. preview.mjs запускает готовую сборку локально. collect.mjs обновляет сохранённые подборки. check.mjs проверяет серверные запросы и валюты.

Покупка происходит только на сайте Steam. Комиссии пополнения не учитываются, поэтому рублёвый эквивалент не является итоговой ценой оплаты. Игры могут быть недоступны в других регионах. Избранное не синхронизируется между устройствами.
